# 사쿠야의 휴대폰 (GitHub Pages 배포용)

- 진입 파일: `index.html`
- 모든 경로는 `index.html` 기준 상대경로(`assets/...`)입니다.
- 이미지 21장은 `assets/` 안에 따로 들어 있습니다. (HTML 안에 포함하지 않음)

## 구조
```
저장소 루트/
├─ index.html
├─ .nojekyll
├─ README.md
└─ assets/
   ├─ posts/   post1.jpg ~ post5.jpg     (지식iN 게시물 스크린샷)
   └─ photos/  photo01.jpg ~ photo16.jpg (사진 앱)
```
> 파일명은 대소문자까지 정확히 유지해야 합니다. (GitHub Pages는 대소문자를 구분합니다.)
